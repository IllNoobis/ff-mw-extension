# ff-mw-extension
Public distribution channel for the **Freeflow** MotiveWave custom study.
- `version.json` — latest release metadata (`latest`, `filename`, `url`, `sha256`, `notes`). The study polls this for auto-updates.
- Release assets — `Freeflow.jar` builds. Download the latest from [Releases](../../releases).
- Install: copy `Freeflow.jar` to `%USERPROFILE%\MotiveWave Extensions\` (root, not `lib\`), then restart MotiveWave.
Source code lives in a private repo; this repo ships only version metadata + built jars.
